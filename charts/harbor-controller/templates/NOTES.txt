Prerequisites before the controller starts:

  Create the Harbor admin password Secret in namespace {{ .Release.Namespace }}:

    kubectl -n {{ .Release.Namespace }} create secret generic harbor-admin-password \
      --from-literal=password=<your-harbor-admin-password>

  The controller will stay in CreateContainerConfigError until this Secret exists.

1. Get the controller pod status:

   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "harbor-controller.name" . }}

2. Verify the controller logs:

   kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "harbor-controller.fullname" . }}

3. Create a HarborProject custom resource:

   cat <<EOF | kubectl apply -f -
   apiVersion: harbor.sealos.io/v1
   kind: HarborProject
   metadata:
     name: my-project
   spec:
     displayName: "My Project"
     owner: "user"
     namespaceRefs:
       - default
   EOF

4. Check HarborProject status:

   kubectl get harborprojects
