╔══════════════════════════════════════════════════════════════╗
║  Harbor Stack deployed – bundled Harbor + Controller        ║
╚══════════════════════════════════════════════════════════════╝

Bundled Harbor (minimal):
  - Harbor Core, Registry, JobService, Database, Redis
  - Portal, Trivy, Notary, ChartMuseum, Exporter → disabled

The chart automatically creates the shared admin password Secret
from .Values.harbor.adminPassword (randomly generated if empty).
Set a custom password during initial install:

  helm install harbor-stack ./charts/harbor-stack \
    --set harbor.enabled=true \
    --set harbor.adminPassword=<your-password>

To change the admin password after deployment, use Harbor's
password-change API or UI first, then update the controller
Secret and restart the controller pod.

1. Wait for Harbor to become ready:

   kubectl -n {{ .Release.Namespace }} get pods \
     -l app.kubernetes.io/component=core

2. The controller will connect to the bundled Harbor at:
   http://harbor.{{ .Release.Namespace }}.svc:80

3. Check the controller logs:

   kubectl -n {{ .Release.Namespace }} logs \
     deployment/{{ .Release.Name }}-harbor-controller

4. Create a HarborProject:

   cat <<EOF | kubectl apply -f -
   apiVersion: harbor.sealos.io/v1
   kind: HarborProject
   metadata:
     name: my-project
   spec:
     displayName: "My Project"
     owner: "user"
     namespaceRefs:
       - default
   EOF

║  Harbor Stack deployed – controller only (external Harbor)  ║
╚══════════════════════════════════════════════════════════════╝

No bundled Harbor was deployed.  The controller expects an
existing Harbor instance.  Make sure:

  - The admin password Secret exists in namespace {{ .Release.Namespace }}:

    kubectl -n {{ .Release.Namespace }} create secret generic harbor-admin-password \
      --from-literal=password=<your-harbor-admin-password>

  - Update the controller's harbor.endpoint to point to your
    external Harbor, e.g.:
    helm upgrade {{ .Release.Name }} ./charts/harbor-stack \
      --set harbor-controller.harbor.endpoint=https://your-harbor.example.com

1. Check the controller logs:

   kubectl -n {{ .Release.Namespace }} logs \
     deployment/{{ .Release.Name }}-harbor-controller

2. Create a HarborProject:

   cat <<EOF | kubectl apply -f -
   apiVersion: harbor.sealos.io/v1
   kind: HarborProject
   metadata:
     name: my-project
   spec:
     displayName: "My Project"
     owner: "user"
     namespaceRefs:
       - default
   EOF
